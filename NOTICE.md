## Assets

### Built-in procedural models

The vessel and munition silhouettes in the player are original procedural
KerbTac artwork covered by the project MIT License. BDArmory names are used
for replay compatibility. The player no longer bundles BDArmory OBJ
conversions or the former KSP craft-export STL.

### Kerbin basemap — restyled derivative

`player/src/assets/kerbin-16k-tacview.webp` is a 15360×7680 basemap generated by
`tools/make_kerbin_basemap_np.py`. It derives its land/sea mask, dry-biome
distribution, and large-scale relief from a Kerbin map rendered in KSP
(Smooney's KSP Maps, https://smooney.space/mapdownloads/,
https://github.com/Smooneychad/KSP-Maps, using Sigma Cartographer and
Parallax), then re-renders the colors, terrain shading, and coastlines with a
different palette. The two smiley artifacts in the source were masked out.

This is **not** an original map and is **not** a clean-room replacement. The
underlying geography and source imagery are part of Kerbal Space Program,
(c) Squad / Take-Two Interactive. Redistribution still carries derivative-work
risk. The original source map is kept locally at
`basemap/kerbin-16k-source.webp` and is not part of the repository or the
release export.

If a map with a clear public license or an original map becomes available, it
should replace this file and this notice should be updated.
